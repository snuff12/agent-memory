**현재 결합 검색은 이 영문 대화 데이터에서 BM25 단어 검색보다 낮은 점수를 받았습니다.**
상위 10개 세션에 필요한 근거를 모두 포함한 문항은 현재 검색이
**277/470개(58.94%)**, BM25 비교군이 **387/470개(82.34%)**입니다.
실제 CLI의 출력 예산까지 적용하면 현재 검색에서 근거 세션 위치가 모두 보이는
문항은 **185/470개(39.36%)**입니다.

이 수치는 근거가 있는 대화 세션을 찾는 성능입니다. 답변 생성과 채점에는 LLM을
사용하지 않았으며, 최종 답변 정확도를 뜻하지 않습니다.

## 전체 점수

| 평가 대상 | 근거 모두 찾음 @5 | 근거 모두 찾음 @10 | 근거 하나 이상 @10 | 순위 점수 MRR |
|---|---:|---:|---:|---:|
| 현재 검색의 전체 후보 | 34.89% | 58.94% | 85.74% | 0.5189 |
| 현재 검색의 CLI 출력, 4,000바이트 | 34.89% | 39.36% | 74.68% | 0.5000 |
| FTS5 BM25 단어 검색 | 72.77% | 82.34% | 95.53% | 0.8320 |

청크 후보 최대 20개에서 세션 ID의 중복을 제거한 뒤 상위 k개를 평가했습니다.
CLI에 보이는 후보가 k개보다 적으면 있는 만큼만 평가합니다. 이 실행에서는 평균
5.68개 세션의 위치가 보였습니다. CLI 행은 별도 검색 알고리즘의 성능이 아니라
출력 예산을 통과한 뒤의 근거 위치 포함률입니다.

## 실행 기록

- 2026-10-14 06:51 UTC에 시작해 전체 실행에 172.558초가 걸렸습니다.
- 전체 500문항을 실행했습니다. 근거가 있는 470문항으로 검색 점수를 계산하고,
  답변 보류 대상인 나머지 30문항에는 검색 점수를 부여하지 않았습니다.
- 서로 분리된 대화 기록에서 세션 기록 23,867개와 청크 134,811개를 색인했습니다.
  원본의 중복 세션 ID 기록 13개도 그대로 보존했습니다.
- 환경은 macOS arm64, Python 3.9.6, SQLite 3.54.0입니다.
  정확한 환경 정보와 엔진·평가 코드의 SHA-256은 전체 결과 JSON에 있습니다.
- 현재 검색 시간은 중앙값 16.962 ms, p95 24.674 ms였습니다.
  준비·색인·출력 형식 처리·원문 읽기·답변 생성 시간은 제외했습니다.
- CLI 출력은 최대 4,000바이트, 평균 3,999.8바이트였습니다. 출처와 헤더를 포함합니다.
- BM25 검색 시간도 JSON에 남겼습니다. 엔진 검색 뒤에 실행하고 정책·무결성 검사를
  반복하지 않으므로, 두 시간을 단독 속도 비교로 해석하면 안 됩니다.

문항별 공개 JSON에는 로컬 `cases.jsonl`의 세션 순위와 점수를 남기고,
중복 정보인 `chunks` 배열만 생략했습니다. 질문·정답·대화 본문·개인 경로는 없습니다.
집계 JSON의 `case_records_sha256`은 로컬 원본 기록의 해시이며, 축약한 공개 JSON의
해시가 아닙니다. 평가 코드를 다시 실행하면 청크 번호를 포함한 원본 기록이 생성됩니다.

## 확인된 한계

이 데이터와 평가 조건에서는 현재 순위 결합 방식이 BM25 비교군보다 불리했습니다.
CLI 출력 제한도 근거 세션 위치가 보이는 비율을 낮췄습니다. 다음 개선에서는
검색 채널별 기여와 출력 예산 배분을 각각 확인할 수 있습니다.

점수를 본 뒤 엔진을 조정하지 않았습니다. 이번 결과만으로 한국어 문서·검토된 프로젝트
기억·원본 갱신·실제 작업 성공률의 성능을 판단할 수는 없습니다.
데이터 출처는 [LongMemEval 공식 정제본](https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned)입니다.
