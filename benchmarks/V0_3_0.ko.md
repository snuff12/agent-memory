# LongMemEval-S 0.3.0 재측정

측정일: 2026-10-16, 엔진 `ff1c3e1`. [English](V0_3_0.md)

**필요한 근거 세션을 모두 찾은 비율은 상위 10개 기준 403/470문항, 85.74%입니다.**
이전 공개 결과 `ea53b90`의 385/470문항, 81.91%보다 18문항·3.83%p 높습니다.
다만 같은 경로에서 새로 실행한 직전 버전 `5c7fda1`도 85.74%입니다.
직전 버전과 0.3.0은 세 평가 방식 모두에서 500문항의 세션 순위와 문항별 지표가
완전히 같습니다.

따라서 이전 공개 점수 대비 상승분은 이번 두 기능을 넣기 전부터 있던 차이입니다.
이 평가에서는 기본 검색만 한 번 실행합니다. 새 위치 찾기·줄 범위 읽기·선택형
의미검색은 실행하지 않으므로, 그 효과를 측정한 점수는 아닙니다.
재측정 과정에서 엔진을 벤치마크에 맞춰 수정하지 않았습니다.

## 전체 점수

‘근거 모두 @k’는 필요한 대화 세션이 상위 k개 안에 전부 있는 비율입니다.
‘하나 이상’은 근거 세션을 하나라도 찾은 비율입니다. 최종 답변 정확도는 아닙니다.

|---|---:|---:|---:|
| 근거 모두 @1 | 25.53% | 24.47% | 24.47% |
| 근거 모두 @5 | 72.34% | 77.02% | 77.02% |
| 근거 모두 @10 | 81.91% | 85.74% | 85.74% |

이전 공개 결과와 문항별로 비교하면 ‘근거 모두 @10’은 **35문항 개선·17문항 하락·
418문항 동일**입니다. ‘근거 모두 @1’은 120문항에서 115문항으로 줄었습니다.
모든 문항이나 지표가 좋아진 것은 아닙니다.

같은 단어를 쓰는 BM25 비교군은 현재 404/470문항, 85.96%로 결합 검색보다 한 문항
높습니다. 이 비교군도 엔진의 현재 검색어 선택을 공유합니다. 과거와 같은 이름이어도
검색어가 고정된 별도 엔진은 아니며, 원 논문의 flat-bm25를 재현한 결과도 아닙니다.

## 같은 조건인지 확인한 내용

데이터는 이전과 같은 LongMemEval-S 정제본입니다. 데이터와 평가 코드의 SHA-256,
전체 500문항의 ID·정답 근거, 목표 2,400자·겹침 240자 분할, 후보 20개,
파일당 최대 두 조각과 CLI 4,000바이트 제한을 유지했습니다. 평가 코드는 수정하지
않았습니다. 근거가 있는 470문항만 점수를 계산하고, 답변 보류 대상 30문항은
진단용으로 남겼습니다. LLM·임베딩·질문 확장·답변 생성은 사용하지 않았습니다.

문항마다 해당 대화 기록만 담은 새 메모리 홈을 만들고 다음 문항 전에 삭제했습니다.
새 버전 실행 결과를 잠시 옮긴 뒤, 직전 버전을 **같은 절대 원문 경로**에서 실행하고
두 결과를 모두 보존했습니다. 이 대조에서는 경로 때문에 생기는 동점 순위·출처 길이
차이를 통제했습니다. 이전 공개 실행은 다른 경로에서 실행했고 검색어 선택·출력
구현도 더 오래된 버전입니다. 그 사이의 어떤 변경이 각 문항의 상승·하락을
일으켰는지까지 이번 실험으로 분리하지는 않았습니다.

점수를 보고 검색 규칙·가중치·별칭·정답·예산·엔진 코드를 바꾸지 않았습니다.
과거에 원인을 분석하는 데 사용한 데이터이므로, 보지 않은 별도 평가 자료라고
주장하지 않습니다. 자세한 정의는 [평가 조건](README.ko.md)을 참고하세요.

새 버전 실행은 218.653초, 직전 버전 대조 실행은 283.522초가 걸렸습니다. 각각 세션 기록 23,867개·조각 134,811개를 색인했고, 중복 세션 ID 기록 13개도 보존했습니다. 새 CLI 출력은 최대 4000바이트·평균 3987.6바이트입니다. 검색 시간은 중앙값 16.721 ms·p95 31.003 ms였습니다. 준비·색인·출력 형식 처리·원문 읽기는 제외한 한 기기의 진단값이며, 통제된 속도 비교는 아닙니다.

공개 문항별 파일은 ID·개수·세션 순위·점수·시간만 골라 저장했습니다.

공개 파일의 해시는 별도 비교 JSON에 있습니다. 데이터 원본·운영 기억·색인은
공개하지 않으며 이전 결과 파일도 그대로 보존했습니다.

`ff1c3e1`을 체크아웃하고 설치한 뒤 다음 명령으로 재측정할 수 있습니다.

```bash
.venv/bin/python -m benchmarks.longmemeval run \
  --output "$HOME/.cache/agent-memory-benchmarks/longmemeval/new-unique-run"
```

같은 고정 데이터를 사용하고 출력 폴더는 새 경로여야 합니다. 경로까지 맞춘 대조는
완료된 결과를 잠시 옮긴 뒤 `5c7fda1`에서 같은 절대 원문 경로로 반복하고 두 결과를
보존합니다. 엔진·평가 코드의 해시도 확인합니다. 다른 경로나 기기에서는 동점 순위,
출처 길이와 시간이 달라질 수 있습니다.
